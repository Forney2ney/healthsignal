# HealthSignal project guidance

Before making significant changes, read `HEALTHSIGNAL_PROJECT.md` and
follow it as the persistent project specification. Inspect existing work
before editing, preserve working functionality, run tests, and keep
`PROJECT_STATUS.md` and `DECISIONS.md` current.

Never fabricate medical claims, dataset details, model metrics or
validation. Clearly label implemented, incomplete, simulated and planned
features.
